# Settings

Open **Settings** in the sidebar. It has two parts, each with its own pages.

## User settings

About you and how you sign in.

- **Profile**: your full name and your email address. Changing the email asks for your current password.
- **Security**: change your password, add or remove passkeys, set up an authenticator app or email codes, and regenerate recovery codes. Changing your password signs you out everywhere else. See [Authentication](authentication.md).
- **Sessions**: every browser and device that is signed in right now. Sign one out, or sign out everywhere else.

## Account settings

About this Watchdog instance. Only owners and administrators can change things here.

- **General**: the version, the address Watchdog runs on, update checks and which sign-in providers are set up.
- **Projects**: every project with a link to its settings, and a delete button. Deleting a project removes its issues, events, performance data, replays, dashboards, alert rules and source maps for good, so you must type the project name to confirm.
- **Team**: invite people and set their roles. See [Team, invites and roles](team.md).
- **Data and retention**: how long each kind of data is kept. See [Data retention](retention.md).
- **API keys**: the keys that let an AI assistant use [MCP](mcp.md).
