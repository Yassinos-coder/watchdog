# Team, invites and roles

## Roles

| Role | Can do |
| --- | --- |
| Owner | Everything, including promoting admins and removing anyone |
| Admin | Manage projects, alerts and integrations; invite and remove members |
| Member | View and triage issues, performance and replays |

Owners and admins must use two-step verification. Nobody can change their own role or remove themselves, and you can only manage people ranked below you.

## Invite someone

Open **Team**, choose **Invite**, enter an email and a role. Watchdog emails a link if [SMTP is set up](alerts/email.md). Otherwise it shows the link so you can send it yourself. Links work once and expire after 7 days. Inviting the same email again replaces the old link.

## Accepting

The invitee opens the link, picks a name and a password (at least 12 characters), and is signed in. If they are an admin they then set up two-step verification.
